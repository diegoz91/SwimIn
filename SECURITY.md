# Sicurezza

Se trovi una vulnerabilità in SwimIn **non aprire una issue pubblica**: scrivi all'indirizzo indicato
nella privacy policy dell'app (o usa *Security › Report a vulnerability* di GitHub, segnalazione privata).
Rispondiamo entro pochi giorni e ti teniamo aggiornato fino alla correzione.

Il modello di sicurezza (permessi per riga, Function `api`, dati privati, cifratura, Content Security
Policy, configurazione consigliata di Appwrite) è descritto in `docs/SETUP-APPWRITE.md`, sezione 13.
